# Majestick FamQ Discord Bot

Официальный Discord бот для семьи Majestick на проекте Majestick RP (GTA 5 RP)

## Функционал

### Система заявок

#### RP заявка
- Никнейм и статик
- OOC имя и возраст
- История фамок
- Почему именно наша фама?
- Прайм-тайм и average онлайн в день

#### CAPT заявка
- Никнейм и статик
- OOC имя и возраст
- Опыт каптов за другие фамки
- Откат сайга/спешик 2+ минуты gungame ангар

#### Медиа заявка
- Никнейм в игре
- Ссылка на твич/кик
- Ссылка на тикток
- Ссылка на ютуб

### Система отпусков
- Выдается роль `Отпуск` с доступами как у гостей канала

### Система баллов (Regentik)

| Действие | Награда |
|----------|---------|
| 100.000$ на баланс семьи | 2 Regentik |
| 1 контракт Грина | 1 Regentik |
| 1 контракт Блю | 2 Regentik |
| 1 контракт Вайта | 3 Regentik |
| 1 МП с семьей | 2 Regentik |
| Час в войсе | 1 Regentik |
| 10 спешиков на склад | 3 Regentik |
| 500 бинтов | 3 Regentik |
| 50 броников | 5 Regentik |
| 1 буст сервера | 15 Regentik |
| Оплата офиса | 5 Regentik |

### Система АФК
- Автоматическое определение неактивных участников

### Система лидерборда
- Топ участников по Regentik баллам

## Команды бота

| Команда | Описание |
|---------|----------|
| !regent | Открыть меню подачи заявки |
| !stats | Показать статистику заявок (админ) |
| !history | Показать историю заявок (админ) |

## Установка и запуск

### Требования
- Python 3.8+
- Discord Bot Token

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/yyangdev/majestick-famq-discord-bot.git

# Перейти в папку проекта
cd majestick-famq-discord-bot

# Установить зависимости
pip install discord.py python-dotenv
```

### Настройка

1. Создайте файл `.env` и добавьте токен бота:
```
TOKEN=ваш_токен_бота
```

2. Создайте на сервере Discord необходимые каналы:
   - Категория `ТИКЕТЫ`
   - Канал `📋утогу-заявок` (для логов)
   - Голосовые каналы: `🔊Обзвон 1`, `🔊Обзвон 2`, `🔊Обзвон 3`

### Запуск

```bash
python main.py
```

    ├── call_voice.py      # Вызов на обзвон

```
